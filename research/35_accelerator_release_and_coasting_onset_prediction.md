# 35. アクセル戻し・惰行開始の予測（エコドライブ系）— 日本語文献を中心に

- 調査日: 2026-11-22
- 論点: B-31。信号・一時停止・追従でのアクセル戻し（惰行開始）を車両信号で予測する文献の、入力・ホライズン・性能・地図/信号情報の要否

## 1. エグゼクティブサマリー

- 「CANのみで、アクセル戻しの何秒前に、どの精度で予測したか」を数値で示す文献は、探した範囲では見つからなかった。
- 国内文献は大半が (a) ナビ・信号・ITS 情報で減速地点を出す方式、(b) 反力・表示で戻しを促す支援、のいずれかで、いずれも地図・信号情報が前提である。
- 量産実装（アイシン・トヨタの「先読みエコドライブ」）は、同じ地点での過去の減速・停止を位置に紐付けて蓄積する方式で、CANのみとは前提が異なる。
- 追従場面では、アクセル戻しがブレーキの前段になるとの報告（シミュレータ）と、アクセル戻しかブレーキかの選択要因（THW・自車速・先行車の運動状態）を回帰した自然走行研究があり、これらは車間・相対速度が CAN に流れる場合に使える。
- 日本大学の大型車追従モデルは、アクセル開度を車間・相対速度・自車情報から時間遅れ付きで回帰する構成で、CAN特徴量だけで作れる可能性がある（数値未確認）。
- 空白: CAN特徴量によるアクセルオフ予測のホライズン別性能。

### 2.1 地図・信号・ITS 情報を使う方式（CANのみの対象外）

1. 先読みエコドライブ用 減速地点推定の開発 / アイシン / 2021（アイシン技報 Vol.25）/ 企業技報。URL: https://www.aisin.com/jp/technology/technicalreview/25/pdf/11.pdf
   - 事実: ナビの地図情報を使い、ドライバがよく減速する地点（一時停止・交差点等）を予測して回生拡大制御を行う。ドライバ操作を位置情報と紐付けて蓄積。1998年製品化の NAVI・AI-SHIFT（アクセルオフに応じたシフトダウン）も紹介。ホライズン・性能値は抜粋になし。地図/信号: 必須
   - 示唆: 【推察】地点単位の学習で、CANのみの要件と相反する。同一場所の再現性を GNSS 無しで代替する課題が残る。
2. トヨタ「先読みエコドライブ」取扱説明書 / トヨタ / 年不明 / 取扱説明書（学術文献ではない）。URL: https://manual.toyota.jp/alphard/3086/phev/ja_JP/contents/nvch04se020405.php

### 2.2 車両信号・先行車運動学のみで説明できるもの

14. 減速方式（ブレーキ入力かペダル入力なしか）の選択要因 / 著者不明 / 2019（DOI から）/ 自然走行、査読論文（Traffic Injury Prevention と推定）。URL: https://informahealthcare.com/doi/abs/10.1080/15389588.2019.1707194
    - 事実: ロジスティック回帰で6要因（交通流、交差点形態、先行車の運動状態、自車の運動状態、自車速度、THW）が有意。先行車が停止中より減速中のほうがアクセルオフを選びやすく、THW と速度が大きいほどペダル入力なしを選びやすい。地図/信号: 交差点形態・信号の有無も候補（扱いは未確認）
    - 示唆: 【推察】自車速・THW・相対速度で「アクセルオフかブレーキか」の分岐確率は説明できそう。ただし「いつ」ではなく「どちらか」の情報で、ホライズン・精度は不明。
15. Analyzing and modelling drivers' deceleration behaviour from normal driving / Deligianni ら（Loughborough 大）/ 2017 / TRR 2663。URL: https://repository.lboro.ac.uk/articles/Analyzing_and_modelling_drivers_deceleration_behaviour_from_normal_driving/9448259/files/17070251.pdf

## 3. 統合アーキテクチャ（12）への反映点

- L2/L3: 「アクセルオフ検出」を独立イベントとして持ち、先行車ありではブレーキ意図の前段特徴量、先行車なし・信号ありでは地図なしの予測は難しいと整理する。【推察】
- L3（R4）: 減速方式の分岐（アクセルオフ/ブレーキ）を、自車速・THW・相対速度から出す小モデルを置く案。【推察】
- ラベル: 「両ペダルオフ」「アクセル開度の閾値割れ（ハンチング除去）」で惰行開始ラベルを CAN から作れる。ただし性能は未検証。【推察】
- L5: アクセルオフを促す警告は、後続車の挙動を変える副作用がありうる（文献8）。
- 地図なし制約: 量産のエコドライブ支援は地点蓄積（地図）方式であり、CANのみでは同方式に勝てない可能性が高い。【推察】
